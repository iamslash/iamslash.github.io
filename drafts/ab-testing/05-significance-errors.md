# 5편. 가설검정의 심장 (2) — 유의수준과 1종·2종 오류

> 시리즈: 밑바닥부터 이해하는 A/B 테스트 통계
> 이 편에서 배우는 것: p-value가 "얼마나 작아야" 유의한지 정하는 문턱(유의수준 α)과, 판정할 때 저지르는 두 종류의 실수(1종·2종 오류).

4편에서 콩마켓의 p-value가 0.005라는 걸 구했습니다. 그런데 막상 이렇게 물으면 말문이 막힙니다.

> "0.005면 유의한 거예요? 그럼 0.04는요? 0.06은요? 도대체 얼마나 작아야 '작은' 건데요?"

어딘가에 **선을 그어야** 합니다. "이 선보다 작으면 유의하다고 인정하겠다"는 그 선이 이번 편의 주인공, **유의수준**입니다.

## 유의수준 α: 미리 그어두는 문턱

**유의수준(significance level, α)** — p-value가 이 값보다 작으면 "통계적으로 유의하다(= H0를 기각한다. 기각 = '틀렸다고 보고 버린다')"고 부르기로, **실험을 시작하기 전에** 정해두는 문턱(threshold)입니다. 관습적으로 **0.05**를 씁니다.

여기서 "미리"가 정말 중요합니다. 데이터를 다 본 다음에 문턱을 정하면, "어? p가 0.06 나왔네? 그럼 문턱을 0.07로 하지 뭐" 같은 자기합리화가 가능해집니다. 내 입맛대로 유의/비유의를 조작할 수 있게 되는 거죠. 그래서 문턱은 실험 시작 전에 못 박아 둡니다.

콩마켓에 적용하면:

- 우리는 실험 전에 **α = 0.05** 로 정해 뒀습니다.
- 결과는 **p = 0.005**.
- **0.005 < 0.05** 이므로 → "유의하다" → H0를 기각 → **"초록 버튼은 파란 버튼과 전환율이 다르다"** 고 선언합니다.

한 가지 꼭 짚고 갑니다. **0.05는 절대 진리가 아닙니다.** 통계학자 로널드 피셔(Ronald Fisher)가 편의상 제안한 **관습**일 뿐입니다. 분야와 리스크에 따라 0.01이나 0.001을 쓰기도 하고, 입자물리학에서는 훨씬 더 빡센 기준(이른바 '5시그마', p ≈ 0.0000003)을 씁니다. 콩마켓 버튼 색 정도라면 0.05로 충분하지만, 결제 로직처럼 실수의 대가가 큰 변경이라면 더 엄격하게 잡는 게 맞습니다. **"왜 하필 0.05인가"에 대한 우주적 이유는 없습니다.**

## 문턱을 정하면, 실수는 두 종류가 생긴다

문턱을 그어 "유의/비유의"를 판정하는 순간, 우리는 틀릴 수 있습니다. 그리고 틀리는 방식은 정확히 두 가지입니다. 표로 보면 한눈에 들어옵니다.

| | 판정: "차이 있다" | 판정: H0 기각 못함 (유의한 차이를 발견하지 못함) |
|---|---|---|
| **실제로 차이 없음** | 1종 오류 (가짜 승자) | 정답 |
| **실제로 차이 있음** | 정답 (검정력) | 2종 오류 (놓침) |

표의 왼쪽 위(1종 오류)와 오른쪽 아래(2종 오류) 두 칸이 실수이고, 나머지 두 칸이 정답입니다. 하나씩 보겠습니다.

## 1종 오류: 가짜 승자를 붙잡는 실수

**1종 오류(Type I error, false positive)** — 진짜로는 차이가 없는데(H0가 참인데) "차이 있다!"고 잘못 선언하는 것입니다. 헛것(우연)을 진짜 효과로 착각하는 거죠. 한마디로 **"가짜 승자(false winner)"** 를 왕좌에 앉히는 실수입니다.

그리고 여기 이번 편에서 가장 중요한 사실이 있습니다.

> **유의수준 α는 H0가 참일 때 1종 오류율의 목표값(또는 상한)입니다.** 잘 보정된 연속형 검정에서는 1종 오류율이 정확히 α이고, 이산·근사 검정에서는 α 이하나 α 근처일 수 있습니다. (전환율처럼 값이 딱딱 끊기는 데이터에서는 정확히 α가 아니라 그 근처로 나올 수 있습니다.)

왜 이렇게 이어질까요? α는 정의상 "H0가 참일 때 p < α가 될 확률"입니다. 그런데 p < α이면 우리는 H0를 기각(= "차이 있다"고 선언)합니다. 즉 "H0가 참인데 기각해버릴 확률"이 바로 1종 오류율입니다. 수준 α인 유효한 검정은 H0가 참일 때 1종 오류율을 α 이하로 제어합니다. 연속형으로 정확히 보정된 검정에서는 α와 같고, 이산·근사 검정에서는 α보다 작거나 α 근처일 수 있습니다. 그래서 문턱을 0.05로 잡으면, **진짜 차이가 없어도 대략 20번에 1번은 우연히 "유의"가 떠서 속게** 됩니다.

## A/A 실험으로 α를 눈으로 보기

말로만 하면 안 와닿으니 코드로 확인해 봅시다. **A/A 실험(A/A test)** 을 씁니다. A/A 실험이란 A와 B가 사실은 **완전히 똑같은** 상태(둘 다 5.0%)로 실험을 돌리는 것입니다. 진짜 차이가 0이니, 여기서 "유의"가 떴다면 그건 **100% 1종 오류**입니다.

콩마켓의 파란 버튼을 두 그룹에게 **똑같이** 보여준다고 상상하세요. 그래도 두 그룹의 전환율은 운 때문에 조금씩 다르게 나옵니다. 가끔은 그 차이가 제법 커서 p < 0.05가 뜹니다. 그런 일이 전체의 몇 %나 될까요? 20만 번 돌려 보겠습니다.

```python
import numpy as np
from scipy import stats

rng = np.random.default_rng(7)
n = 22_000
p_true = 0.05          # A와 B가 '진짜로 똑같은' A/A 실험
trials = 200_000
alpha = 0.05

def one_experiment_pvalue():
    A = rng.binomial(n, p_true, trials)
    B = rng.binomial(n, p_true, trials)
    pbar = (A + B) / (2*n)
    se = np.sqrt(pbar*(1-pbar)*(2/n))
    z = (B/n - A/n) / se
    return 2 * (1 - stats.norm.cdf(np.abs(z)))   # z를 양측 p-value로 변환. 원리는 6편, 여기선 'p값을 뽑는다'만 믿고 넘어가세요.

pvals = one_experiment_pvalue()
print(f"'유의'로 잘못 뜬 비율(alpha=0.05) = {np.mean(pvals < alpha):.3f}")  # ≈ 0.05
for a in (0.01, 0.05, 0.10):
    print(f"  alpha={a:.2f} -> 1종 오류율 {np.mean(pvals < a):.3f}")
```

돌려 보면 이렇게 나옵니다.

```
'유의'로 잘못 뜬 비율(alpha=0.05) = 0.049
  alpha=0.01 -> 1종 오류율 0.010
  alpha=0.05 -> 1종 오류율 0.049
  alpha=0.10 -> 1종 오류율 0.099
```

진짜로 아무 차이가 없는데도, 약 **4.9% ≈ 5%** 의 실험이 우연히 "유의"로 떴습니다. 이게 α = 0.05의 진짜 의미입니다. 그리고 문턱을 0.01로 조이면 1종 오류율도 약 1%로, 0.10으로 풀면 약 10%로 **α를 따라 움직입니다.** 수준 α인 유효한 검정은 H0가 참일 때 1종 오류율을 α 이하로 제어하는데, 이 A/A 실험처럼 연속형으로 정확히 보정된 경우에는 그 값이 α와 같게 나옵니다(이산·근사 검정에서는 α보다 작거나 α 근처일 수 있습니다). "1종 오류율 ≈ α"가 숫자로 확인되는 순간이죠.

## 2종 오류: 진짜를 놓치는 실수

반대 방향의 실수도 있습니다. **2종 오류(Type II error, false negative)** — 진짜 차이가 있는데도 유의한 차이를 **발견하지 못하는** 것입니다. 초록 버튼이 실제로 더 좋은데, 실험이 그걸 잡아내지 못하는 상황이죠.

- 2종 오류가 일어날 확률을 **β(beta)** 라고 부릅니다.
- 그 반대, **검정력(power) = 1 − β** 는 "진짜 차이가 있을 때 그걸 **제대로 잡아낼** 확률"입니다.

콩마켓 실험은 검정력 80%(= β 20%)를 목표로 표본 크기(arm당 22,000명)를 정했습니다. 즉 "진짜 차이가 설계값인 0.6%p이고 독립성·표본 크기 등 가정이 맞을 때 약 80% 확률로 유의하게 검출한다"를 목표로 설계한 거죠. 이 계산과 표본 설계는 7편의 주제입니다. 여기서는 **검정력 = 1 − β = 진짜를 잡아낼 확률** 이라는 연결고리만 기억하면 됩니다.

한 가지 궁금증. 1종 오류율은 α로 딱 정해지는데, 왜 2종 오류율 β는 딱 안 정해질까요? "차이가 있다"에는 **크기가 여러 개**이기 때문입니다. 차이가 0.1%p인지 1%p인지에 따라 놓칠 확률이 달라집니다. 차이가 클수록 놓치기 어렵고(β↓), 표본이 클수록 놓치기 어렵습니다(β↓). 그래서 β는 "얼마짜리 차이를 기준으로 하느냐"에 달려 있고, 이 기준 차이가 바로 MDE(최소 탐지 효과)입니다 — 역시 7편에서 다룹니다.

## 비유: 화재경보기와 스팸 필터

두 오류가 헷갈리면 이 비유를 떠올리세요.

**화재경보기**
- 불이 안 났는데 울림 = **1종 오류(false alarm)**. 멀쩡한데 소란.
- 불이 났는데 안 울림 = **2종 오류**. 진짜 위험을 놓침.
- 경보를 너무 예민하게(문턱을 낮게) 맞추면 오작동(1종)이 늘고, 너무 둔감하게 맞추면 놓침(2종)이 늘어납니다.

**스팸 필터**
- 멀쩡한 메일을 스팸함으로 보냄 = **1종 오류**.
- 스팸을 받은편지함으로 통과시킴 = **2종 오류**.

## 트레이드오프: 둘 다 공짜로 줄일 수는 없다

여기가 핵심입니다. **α를 낮추면(문턱을 더 빡세게 잡으면) 2종 오류는 늘어납니다.**

문턱을 0.05에서 0.01로 조이면, 가짜 승자(1종)를 붙잡을 확률은 줄어듭니다. 좋은 일이죠. 하지만 그만큼 **진짜 차이도 "유의"로 인정받기 어려워져서**, 진짜를 놓칠 확률(2종)이 늘어납니다. 반대로 문턱을 풀면 진짜는 잘 잡지만 가짜 승자가 늘어나고요. 시소를 떠올리면 됩니다. 한쪽을 누르면 다른 쪽이 올라옵니다.

그럼 2종 오류를 1종 오류와 **함께** 줄일 방법은 없을까요? 열쇠는 역시 **표본을 늘리는 것**입니다. 표본을 늘리면 같은 α에서 β를 낮출 수 있습니다(검정력↑). 다만 표본만 늘리면 명목 1종 오류율은 여전히 α 그대로입니다. 두 오류를 모두 낮추려면 표본을 늘린 뒤 α도 더 작게 정해, 더 엄격한 문턱에서도 목표 검정력을 유지해야 합니다. 이게 실험 설계(7편)의 핵심입니다.

실무 관습은 보통 **α = 0.05, 검정력 = 0.80(β = 0.20)** 을 기본값으로 잡습니다. 즉 가짜 승자는 5%, 놓침은 20%까지 감수하겠다는 뜻이죠. 왜 비대칭이냐면, 보통 없는 효과를 있다고 착각해서 잘못된 변경을 배포하는 비용(가짜 승자)이 더 비싸다고 보기 때문입니다.

## 프레임워크에서 어디에 쓰이나

GrowthBook 같은 프레임워크에서 **"significance threshold"**(보통 0.05, 또는 신뢰수준 95%로 표기)를 설정하는 자리가 바로 α입니다. 프레임워크는 이 값을 기준으로 각 지표를 초록(승)/빨강(패)/회색(미결)으로 칠합니다. 또 실험 설계 화면의 "표본 크기·기간 계산기"는 목표 검정력(1 − β, 보통 80%)과 α, MDE를 받아 필요한 표본을 역산합니다(7편). 즉 **α와 β는 프레임워크가 "언제 승자를 선언하고 언제 더 기다릴지"를 정하는 두 개의 손잡이**입니다.

## 한 줄 정리

유의수준 α는 "가짜 승자(1종 오류)를 얼마나 감수할지" 미리 정한 문턱이고(H0가 참일 때 1종 오류율을 그 값 이하로 제어), 이걸 빡세게 조일수록 진짜를 놓칠 위험(2종 오류)이 커지므로, 둘의 균형은 결국 표본 크기로 맞춥니다.
