# 2편. 정규분포와 중심극한정리

> 시리즈: 밑바닥부터 이해하는 A/B 테스트 통계
> 이 편에서 배우는 것: 왜 A/B 테스트의 거의 모든 계산이 "종모양 곡선" 하나로 굴러가는지.

1편에서 우리는 데이터 한 덩어리를 평균·중앙값·표준편차 같은 숫자 몇 개로 요약했습니다. 그런데 콩마켓 실험을 실제로 돌려 보면 이상한 점이 하나 있습니다. 같은 초록 버튼(B)을 오늘 22,000명에게 보여줘도 전환율이 5.6%, 내일 다시 22,000명에게 보여줘도 5.5%, 그 다음엔 5.7%… 이렇게 결과가 매번 조금씩 흔들립니다. 이 "흔들림"이 어떤 모양으로 흔들리는지를 알아야, 나중에 "B가 정말 A보다 나은 건가, 아니면 그냥 운인가?"를 판단할 수 있습니다.

그 흔들림의 모양이 바로 이 편의 주인공, **정규분포**입니다.

## 종모양이란 무엇인가 — 정규분포

**정규분포(normal distribution)** — 가운데(평균)가 가장 볼록하고 양옆으로 갈수록 낮아지는, 좌우 대칭의 종(bell) 모양 분포입니다. "평균 근처 값은 자주 나오고, 평균에서 멀어질수록 드물게 나온다"를 그림으로 그린 것입니다.

한번 상상해 봅시다. 콩마켓 단골 손님들의 키를 재서 히스토그램을 그리면 어떤 모양일까요? 170cm 근처에 사람이 가장 많이 몰리고, 150cm나 190cm처럼 극단으로 갈수록 사람 수가 확 줄어듭니다. 시험 점수, 몸무게, 측정 오차… 자연에서 관찰되는 많은 값들이 이런 종모양을 그립니다.

정규분포는 딱 두 개의 숫자로 완전히 결정됩니다.

- **평균(mean, μ)**: 종의 꼭대기가 어디에 있는가 (좌우 위치)
- **표준편차(standard deviation, σ)**: 종이 얼마나 퍼져 있는가 (폭). 작으면 뾰족하고, 크면 펑퍼짐합니다.

종모양에는 아주 편리한 성질이 하나 있습니다. **평균에서 좌우로 표준편차 2개(정확히는 1.96개) 안쪽에 전체의 약 95%가 들어온다**는 것입니다. 조금 더 정확히는 ±1σ 안에는 약 68%, ±2σ(정확히 1.96σ) 안에는 약 95%가 들어옵니다. 이 "1.96"이라는 숫자는 앞으로 신뢰구간(3편)에서도, p-value(4편)에서도 계속 튀어나옵니다. 지금은 "종모양이면 95%가 ±2σ 안에 있다" 정도만 기억해 두세요.

```python
import numpy as np

rng = np.random.default_rng(0)
heights = rng.normal(loc=170, scale=6, size=100_000)  # 평균 170, 표준편차 6

within_2sd = np.mean(np.abs(heights - 170) <= 1.96 * 6)
print(f"평균 ±1.96σ 안에 든 비율: {within_2sd:.3f}")
# 출력 예: 평균 ±1.96σ 안에 든 비율: 0.950  → 약 95%
```

## 그런데 왜 하필 종모양이 이렇게 자주 나올까 — 중심극한정리

여기서 자연스러운 의문이 생깁니다. "세상 데이터가 다 종모양은 아니잖아요?" 맞습니다. 콩마켓의 결제액만 봐도 대부분 1~3만원인데 가끔 12만원짜리 원두 세트를 사는 손님이 있어서, 히스토그램이 오른쪽으로 길게 꼬리를 끄는 **비대칭** 모양입니다(1편의 `[1,1,2,2,2,3,3,4,5,12]`을 떠올려 보세요). 전환 여부는 더 극단적입니다. 손님 한 명은 "샀다(1)" 아니면 "안 샀다(0)", 딱 두 값뿐이라 종모양은커녕 막대 두 개짜리 분포입니다.

그런데도 A/B 테스트가 종모양에 기댈 수 있는 이유가 바로 통계학에서 가장 마법 같은 정리, **중심극한정리(central limit theorem, CLT)** 덕분입니다.

> **중심극한정리** — 관측값들이 서로 독립이고 같은 분포에서 나왔으며 분산이 유한하다면, 표본이 커질수록 **표본평균의 분포**가 정규분포에 가까워집니다. 원본 데이터 자체가 정규분포로 바뀌는 건 아닙니다. 콩마켓 말로 풀면, 한 방문자의 구매가 다른 방문자의 구매를 직접 결정하지 않고(독립), 같은 모집 규칙으로 들어오며(같은 분포), 한 사람의 값이 끝없이 커지지 않는다(유한분산)는 조건입니다. 한 사용자의 방문 20회를 서로 다른 20명처럼 세거나 특정 요일 고객만 한 arm에 몰리면 이 단순한 CLT를 그대로 쓰기 어렵습니다 — 콩마켓처럼 방문자를 한 번씩 무작위로 세면 걱정 없습니다.

핵심은 "원본 데이터"가 아니라 "**표본 평균**"이 종모양이 된다는 점입니다. 표본이 클수록 그 종모양은 더 매끈해집니다.

비유를 들어 볼까요. 주사위 한 개를 굴리면 1~6이 고르게 나옵니다(평평한 분포, 종모양이 전혀 아님). 그런데 주사위를 **30개씩** 굴려서 그 평균을 적고, 이 일을 수천 번 반복하면, 적어 놓은 평균값들은 3.5 근처에 종모양으로 몰립니다. 극단적으로 평균이 1에 가까우려면 30개가 전부 1이 나와야 하는데, 그런 일은 거의 없으니 가운데로 쏠리는 겁니다. 개별 값은 제멋대로여도, 여럿을 평균 내면 극단이 서로 상쇄되면서 가운데로 모입니다.

## 콩마켓에 적용하기 — 5%짜리 동전 22,000번 던지기

이제 이걸 콩마켓 전환율에 붙여 봅시다. 방문자 한 명이 구매할 확률이 5%라고 합시다. 이건 마치 **앞면이 나올 확률이 5%인 찌그러진 동전**을 한 번 던지는 것과 같습니다. 앞면(구매)=1, 뒷면=0.

- 동전 **한 번**의 분포: 막대 두 개(0과 1). 종모양과 거리가 멉니다.
- 동전 **22,000번**을 던져 나온 "앞면 개수(=구매 수)"의 분포: 놀랍게도 종모양에 가깝습니다.

왜냐하면 구매 수 = 22,000개의 0/1을 전부 더한 값이고, 합은 평균에 22,000을 곱한 것이니 본질적으로 표본 평균과 같기 때문입니다. 구매 수는 정확히는 이산 **이항분포(binomial distribution)** — 성공/실패로 갈리는 시도(구매/미구매)를 여러 번 했을 때 "성공이 몇 번 나오나"가 따르는 분포 — 지만, 기대 성공 수 np=1,100과 기대 실패 수 n(1−p)=20,900이 모두 커 정규분포로 매우 잘 근사됩니다. 왜 np와 n(1−p)가 둘 다 커야 하냐면, 구매가 22,000명 중 3~4명뿐이면 구매 수가 0·1·2·3 몇 값에만 몰려 종모양이 안 됩니다. 성공(1,100)도 실패(20,900)도 넉넉해야 매끈한 종이 됩니다. 이론적으로 이 종모양의 중심과 폭은 이렇습니다.

- 중심(평균 구매 수) = 22,000 × 0.05 = **1,100건**
- 폭(표준편차) = √(22,000 × 0.05 × 0.95) ≈ **32.3건**

(이 √(n·p·(1−p))는 "동전 n번에 앞면 개수가 얼마나 출렁이나"를 주는 표준 공식이며 3편에서 전환율 버전으로 다시 만납니다.)

즉 5%짜리 동전을 22,000번 던지면 구매 수는 대개 **1,100 ± 32건**(±1 표준편차라 약 68% 범위이며, 약 95% 범위는 대략 ±63건입니다) 근처에서 종모양으로 흔들립니다. 실험 A(파랑)의 실제 구매 수가 정확히 1,100이었다는 걸 기억하면, "1,100은 우연이 만든 자연스러운 중심값"이라는 감이 옵니다.

Python으로 직접 던져서 히스토그램이 종모양이 되는지 확인해 봅시다.

```python
import numpy as np

rng = np.random.default_rng(42)
p, n = 0.05, 22_000

# "22,000명 실험"을 5,000번 반복한다.
# 매 실험마다 구매 수를 세고, 전환율(구매 수 / n)을 기록한다.
conversion_rates = []
for _ in range(5_000):
    visitors = rng.random(n) < p      # 각 방문자가 구매했는가? (True/False)
    buys = visitors.sum()             # 이번 실험의 구매 수
    conversion_rates.append(buys / n) # 이번 실험의 전환율

conversion_rates = np.array(conversion_rates)
print(f"전환율들의 평균 : {conversion_rates.mean():.4f}   (기대값 0.0500)")
print(f"전환율들의 표준편차: {conversion_rates.std():.5f} (이론값 {np.sqrt(p*(1-p)/n):.5f})")
# 출력 예:
#   전환율들의 평균 : 0.0500   (기대값 0.0500)
#   전환율들의 표준편차: 0.00145 (이론값 0.00147)
```

이 `conversion_rates`를 히스토그램으로 그리면(아래 코드), 원본은 0/1 막대 두 개짜리였는데도 결과는 5% 주변에 매끈한 종모양이 나타납니다.

```python
import numpy as np

# 위에서 만든 conversion_rates로 텍스트 히스토그램을 그려 본다.
counts, edges = np.histogram(conversion_rates, bins=15)
for c, left in zip(counts, edges[:-1]):
    print(f"{left*100:5.2f}% | {'#' * (c * 60 // counts.max())}")
# 실제 출력 (seed=42, bins=15 — 가운데로 갈수록 막대가 길어지는 종모양):
#    4.40% |
#    4.48% |
#    4.55% |
#    4.63% | ###
#    4.70% | ###########
#    4.78% | ############################
#    4.85% | #############################################
#    4.93% | #########################################################
#    5.00% | ############################################################
#    5.08% | #########################################
#    5.15% | ###########################
#    5.23% | ############
#    5.31% | ####
#    5.38% | #
#    5.46% |
```

가운데(5.00%)가 가장 높고 양옆으로 갈수록 낮아지는, 교과서에 나오는 바로 그 종모양입니다. 개별 방문자는 사거나 안 사거나 둘 중 하나였지만, 22,000명의 평균(전환율)은 이렇게 종모양으로 정리됩니다. 이게 CLT의 힘입니다.

한 가지 덧붙이면, 이 성질은 전환율 같은 비율에만 통하는 게 아닙니다. 오른쪽으로 꼬리가 긴 콩마켓 **방문자당 매출**(비구매자는 0원)도 방문자를 충분히 많이 모아 그 표본평균을 구하면, 그 표본평균의 분포 역시 종모양으로 수렴합니다. 그래서 뒤에서 방문자당 매출 같은 연속형 지표를 다룰 때도 같은 도구를 쓸 수 있습니다.

## 왜 이게 A/B 테스트의 "마법 열쇠"인가

정리하면 이렇습니다. 우리가 실험에서 실제로 재는 값은 전환율(비율)이거나 비구매자는 0원인 방문자당 매출의 표본평균입니다. 그리고 이 값들은 **표본에서 계산한 평균**의 일종입니다. CLT는 이렇게 말합니다.

> 표본이 충분히 크면, 우리가 잰 전환율/평균이 흔들리는 모양은 **종모양(정규분포)이다.**

종모양이라는 걸 알면 엄청나게 편해집니다. 왜냐하면 종모양은 평균과 표준편차 딱 두 숫자로 완전히 설명되고, "±1.96 안에 95%" 같은 규칙이 그대로 성립하기 때문입니다. 덕분에 우리는 이런 질문들에 숫자로 답할 수 있게 됩니다.

- 이 전환율은 얼마나 정확한가? → 종의 폭으로 표현 (3편: 표준오차·신뢰구간)
- B가 A보다 높게 나온 게 우연의 범위 안인가? → 종모양 위 어디쯤인지로 판단 (4~6편: p-value·z-test·t-test)

즉, 뒤 편들에서 나올 z, t, 신뢰구간 같은 "정규 기반 도구"들은 전부 이 CLT라는 열쇠가 문을 열어 준 덕분에 쓸 수 있는 것입니다. 종모양이 보장되지 않으면 그 도구들은 근거를 잃습니다. 다만 이 마법에도 조건이 있다는 점은 짚어 둘게요. 표본이 너무 작거나(수십 명 수준) 전환율이 0%/100%에 지나치게 붙어 있으면 종모양 근사가 잘 안 맞습니다. 우리 콩마켓은 arm당 22,000명이라 걱정 없는 편입니다.

## 프레임워크에서 어디에 쓰이나

GrowthBook 같은 A/B 테스트 프레임워크가 "이 실험은 통계적으로 유의합니다"라고 초록 불을 켤 때, 그 판단의 밑바닥에는 거의 항상 "지표의 표본 평균이 정규분포를 따른다"는 CLT 가정이 깔려 있습니다. 프레임워크는 이 가정 위에서 표준오차를 구하고(3편), 신뢰구간을 그리고, z-통계량으로 p-value를 계산합니다(6편). 반대로 표본이 너무 작거나 지표가 극단적으로 치우쳐 CLT 가정이 깨지는 상황을 감지해 경고를 띄우는 로직도 여기서 출발합니다. 정규분포와 CLT는 프레임워크 통계 엔진의 "표준 좌표계"인 셈입니다.

## 한 줄 정리

관측값이 독립·동일분포이고 분산이 유한하다는 조건에서, 표본이 커지면 원자료가 아니라 **표본평균(전환율)의 분포**가 종모양에 가까워지고, 이 종모양 하나가 A/B 테스트의 모든 통계 계산을 떠받칩니다.
