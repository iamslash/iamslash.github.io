# 3편. 일부로 전체 추측하기 — 표준오차와 신뢰구간

> 시리즈: 밑바닥부터 이해하는 A/B 테스트 통계
> 이 편에서 배우는 것: 22,000명이라는 "일부"만 보고 전체를 추측할 때, 그 추측이 얼마나 정확한지를 숫자로 표현하는 법.

2편에서 우리는 전환율의 흔들림이 종모양이라는 걸 봤습니다. 콩마켓 실험에서 초록 버튼(B)의 전환율은 5.60%로 나왔습니다. 그런데 이 5.60%를 곧이곧대로 믿어도 될까요? 만약 다른 22,000명을 뽑았다면 5.4%나 5.8%가 나왔을 수도 있는데 말이죠. 이 편에서는 "5.60%가 얼마나 믿을 만한 값인지"를 폭(범위)으로 표현하는 법을 배웁니다. 이게 **표준오차**와 **신뢰구간**입니다.

## 전체를 다 볼 수 없다 — 모집단과 표본

먼저 두 단어를 구분합시다.

- **모집단(population)** — 우리가 진짜 알고 싶은 전체 대상. 콩마켓 초록 버튼을 앞으로 마주칠 **모든 방문자**입니다. 미래의 손님까지 포함하니 사실상 무한대이고, 절대 전부 관측할 수 없습니다.
- **표본(sample)** — 그중 우리가 실제로 관측한 일부. 이번 실험에 들어온 **22,000명**입니다.

우리가 정말 알고 싶은 건 모집단의 진짜 전환율(이걸 **참값**이라고 부릅시다)인데, 그건 볼 수 없습니다. 그래서 표본 22,000명에서 나온 5.60%로 그 참값을 **추측**합니다. 여론조사가 국민 5천만 명에게 다 묻지 않고 1,000명에게 물어 전체 여론을 추측하는 것과 똑같습니다. "일부로 전체를 추측한다" — 이것이 통계적 추정의 본질입니다.

문제는, 일부만 봤으니 추측이 정확히 맞을 리 없다는 겁니다. 표본이 바뀌면 답도 바뀝니다.

## 추측은 얼마나 흔들리나 — 표준오차

2편의 동전 시뮬레이션을 떠올려 보세요. 같은 5% 동전을 22,000번 던져도 전환율은 매번 5.0% 근처에서 조금씩 달랐습니다. 이 "표본이 바뀔 때 전환율이 출렁이는 정도"의 크기가 바로 **표준오차**입니다.

> **표준오차(standard error, SE)** — 표본에서 구한 추정치(여기서는 전환율)가 표본이 바뀜에 따라 얼마나 출렁이는지, 그 흔들림의 크기. 2편에서 그린 종모양의 **폭**이 바로 이 SE입니다.

비율(전환율)의 표준오차는 공식이 간단합니다.

```
SE = sqrt( p(1 - p) / n )
```

- `p` = 표본에서 관측한 전환율
- `n` = 표본 크기(방문자 수)

공식에서 두 가지 직관을 읽을 수 있습니다. 분모에 `n`이 있으니 **표본이 커질수록 SE는 작아진다**(추측이 더 안정적이다). 그리고 `p(1-p)`는 p가 0.5일 때 가장 크고 0이나 1에 가까울수록 작아지니, 전환율이 극단적일수록 흔들림이 작습니다.

콩마켓 B에 넣어 봅시다. p = 0.056, n = 22,000.

```
SE = sqrt(0.056 × 0.944 / 22,000) = sqrt(0.052864 / 22,000) ≈ 0.001550
```

즉 B의 전환율 추정치는 표준오차가 약 **0.00155(=0.155%p)** 입니다. 흥미롭게도 이 값은 2편 시뮬레이션에서 나온 전환율들의 표준편차(≈0.00147)와 거의 같습니다(딱 떨어지지 않는 건 2편 시뮬레이션은 p=5.0%로, 지금 B는 p=5.6%로 살짝 다르게 넣었기 때문입니다. 같은 p면 정확히 일치합니다). 우연이 아니라, 표준오차가 바로 "그 흔들림"을 공식으로 예측한 값이기 때문입니다.

### 헷갈리지 마세요 — 표준편차 vs 표준오차

이름이 비슷해서 가장 많이 헷갈리는 둘입니다. 확실히 구분합시다.

- **표준편차(standard deviation)** — **데이터 하나하나가** 서로 얼마나 퍼져 있는가. 예: 콩마켓 결제액은 1만원짜리도 12만원짜리도 있어서 표준편차가 큽니다(1편에서 3.07만원). 손님을 아무리 많이 모아도 개인차 자체는 그대로라, 표준편차는 크게 줄지 않습니다.
- **표준오차(standard error)** — **그 데이터로 계산한 추정치(평균·전환율)가** 얼마나 출렁이는가. 표본을 키우면 추정치는 점점 안정되므로 표준오차는 계속 작아집니다.

둘은 이렇게 연결됩니다. **표준오차 = 표준편차 ÷ √n**. 개별 데이터의 퍼짐을 √n으로 나눠 준 것이죠. 실제로 전환 여부(0/1) 한 명의 표준편차는 √(0.056×0.944) ≈ 0.230인데, 이걸 √22,000 ≈ 148.3으로 나누면 0.230 / 148.3 ≈ 0.00155 로 위의 SE와 정확히 같습니다.

한 줄로 기억하세요. **표준편차는 "데이터가 얼마나 퍼졌나", 표준오차는 "내 추측이 얼마나 흔들리나".**

## 추측에 범위를 붙이자 — 신뢰구간

이제 "5.60%"라는 점 하나 대신, "이쯤에서 저쯤 사이일 것"이라는 **범위**로 답해 봅시다. 2편에서 배운 종모양의 성질 "평균 ±1.96σ 안에 95%가 들어온다"를 그대로 씁니다. 여기서 σ 자리에 표준오차를 넣으면 됩니다.

> **신뢰구간(confidence interval, CI)** — 95% 신뢰구간은 같은 절차로 실험과 구간 생성을 반복할 때, 만들어진 구간의 약 95%가 참값을 포함하도록 설계된 범위입니다. 계산은 `추정치 ± 1.96 × SE` 로 합니다.

B에 적용해 봅시다.

```
95% CI = 5.60% ± 1.96 × 0.155%p
       = 5.60% ± 0.30%p
       = [5.30%, 5.90%]
```

이렇게 읽습니다. 이번에 계산된 구간은 **[5.30%, 5.90%]**이며, 이 구간을 만든 절차의 장기 포함률이 95%입니다. 점 하나(5.60%)로 단정하는 것보다, 이 범위가 훨씬 정직한 답입니다.

### 신뢰구간을 오해하지 마세요

여기서 아주 흔한 오해가 있습니다. "95% 신뢰구간 [5.30%, 5.90%]는 참값이 이 범위 안에 있을 확률이 95%다"라고요. 아쉽지만 정확한 해석은 아닙니다. 참값은 이미 정해진 하나의 숫자라 "확률"로 말할 대상이 아닙니다. 올바른 해석은 이렇습니다.

> **같은 실험을 똑같은 방식으로 100번 반복해서 매번 신뢰구간을 만들면, 그중 약 95개의 구간이 참값을 품는다.**

즉 95%는 "이 특정 구간"이 아니라 "구간을 만드는 절차"의 성공률입니다. 우리가 이번에 얻은 [5.30%, 5.90%]는 그 95개 중 하나이길 기대하는 겁니다. 실무에서는 "참값이 이 근처일 것"이라고 느슨하게 쓰긴 하지만, 정확한 의미는 이렇게 알아 두는 게 좋습니다.

## 표본이 커지면 구간이 좁아진다

SE 공식의 분모에 `n`이 있었죠. 표본을 키우면 SE가 줄고, 따라서 신뢰구간도 좁아집니다. 좁은 구간 = 더 정밀한 추측입니다. 콩마켓 전환율(약 5.6%)을 기준으로 표본 크기별 95% CI 반폭(± 값)을 보면 이렇습니다.

| 표본 크기 n | 95% CI 반폭 |
|---|---|
| 500 | ±2.0%p |
| 2,000 | ±1.0%p |
| 5,000 | ±0.64%p |
| 22,000 | ±0.30%p |

n이 4배가 되면 반폭은 절반이 됩니다(√n 이 2배가 되니까요). 500명일 땐 "5.6% ± 2%p"라 4%대인지 7%대인지도 흐릿하지만, 22,000명이면 "5.6% ± 0.3%p"로 꽤 또렷해집니다. 콩마켓이 arm당 22,000명이나 모은 이유가 여기 있습니다. 작은 차이를 또렷하게 보려면 그만큼 표본이 필요합니다(자세한 계산은 7편 검정력에서).

## 두 그룹의 차이에도 구간을 — "유의"의 냄새

지금까지는 B 하나의 전환율을 다뤘습니다. 하지만 A/B 테스트에서 진짜 궁금한 건 **B가 A보다 나은가**, 즉 두 전환율의 **차이**입니다. 차이(B − A)에도 똑같이 신뢰구간을 씌울 수 있습니다. 두 그룹의 흔들림이 합쳐지므로 SE 공식은 이렇게 바뀝니다. A와 B가 독립이면 두 잡음의 분산을 더하므로 SE_diff² = SE_A² + SE_B² 입니다.

```
SE_diff = sqrt( pA(1-pA)/nA + pB(1-pB)/nB )
```

콩마켓 숫자(A: 5.00%, B: 5.60%, 각 22,000명)를 넣으면 SE_diff ≈ 0.002136, 차이는 +0.60%p 이고 95% CI는 이렇게 나옵니다.

```
차이(B − A)의 95% CI = +0.60%p ± 1.96 × 0.2136%p
                     = [+0.18%p, +1.02%p]
```

이 구간을 자세히 보세요. **양 끝이 모두 0보다 큽니다.** 즉 "차이가 0이다(= B와 A가 똑같다)"라는 가능성이 이 95% 범위 밖으로 밀려나 있습니다. 이건 아주 중요한 신호입니다. 신뢰구간이 0을 포함하지 않으면, "B가 A보다 낫다"는 결론이 통계적으로 **유의**하다는 냄새가 납니다. 반대로 구간이 0을 걸치고 있었다면(예: [−0.2%p, +1.4%p]) "차이가 없을 수도 있다"고 봐야 했겠죠.

이 "0을 포함하느냐"라는 판단은 사실 4~6편에서 배울 **가설검정·p-value**와 동전의 양면입니다. 지금은 "신뢰구간이 0을 안 건드리면 유의의 냄새가 난다" 정도만 감으로 챙겨 두세요.

## Python으로 검증하기

지금까지의 손계산이 맞는지 코드로 직접 확인해 봅시다.

```python
import math

# 콩마켓 최종 결과
nA, xA = 22_000, 1_100   # A(파랑): 방문 22,000, 구매 1,100
nB, xB = 22_000, 1_232   # B(초록): 방문 22,000, 구매 1,232

pA = xA / nA             # 0.0500
pB = xB / nB             # 0.0560
z = 1.96                 # 95% 신뢰수준

# 1) B 단일 전환율의 95% 신뢰구간
se_B = math.sqrt(pB * (1 - pB) / nB)
lo_B, hi_B = pB - z * se_B, pB + z * se_B
print(f"B의 SE = {se_B:.6f}")                       # 0.001550
print(f"B의 95% CI = [{lo_B*100:.2f}%, {hi_B*100:.2f}%]")  # [5.30%, 5.90%]
print(f"  → 반폭 ±{z*se_B*100:.2f}%p")               # ±0.30%p

# 2) 차이(B - A)의 95% 신뢰구간
se_diff = math.sqrt(pA*(1-pA)/nA + pB*(1-pB)/nB)
diff = pB - pA
lo_d, hi_d = diff - z*se_diff, diff + z*se_diff
print(f"\n차이 SE = {se_diff:.6f}")                  # 0.002136
print(f"차이(B-A) = {diff*100:+.2f}%p")              # +0.60%p
print(f"차이의 95% CI = [{lo_d*100:+.2f}%p, {hi_d*100:+.2f}%p]")  # [+0.18%p, +1.02%p]
print("0을 포함하는가?", lo_d <= 0 <= hi_d)          # False → 유의의 냄새
```

```
# 실제 출력
B의 SE = 0.001550
B의 95% CI = [5.30%, 5.90%]
  → 반폭 ±0.30%p

차이 SE = 0.002136
차이(B-A) = +0.60%p
차이의 95% CI = [+0.18%p, +1.02%p]
0을 포함하는가? False
```

본문의 손계산과 코드 출력이 정확히 일치합니다. SE 0.00155 → B 구간 [5.30%, 5.90%], SE_diff 0.002136 → 차이 구간 [+0.18%p, +1.02%p], 그리고 이 구간은 0을 포함하지 않습니다.

## 프레임워크에서 어디에 쓰이나

GrowthBook 같은 A/B 프레임워크의 결과 화면에서 각 지표 옆에 붙는 "±" 오차 막대와 범위 표시가 바로 이 신뢰구간입니다. 프레임워크는 실험 데이터가 쌓일 때마다 위 두 공식(단일 SE, 차이 SE)으로 표준오차를 계산해 구간을 그리고, 특히 **차이의 신뢰구간이 0을 넘어섰는지**를 실험 성공 판정의 핵심 근거로 씁니다. 표본이 쌓일수록 구간이 좁아지며 실험이 "결론에 수렴"하는 과정도, 분모의 n이 커지며 SE가 줄어드는 이 원리 그대로입니다.

## 한 줄 정리

일부(표본)로 전체(모집단)를 추측할 때, 그 추측의 흔들림은 **표준오차**로 재고 믿을 만한 범위는 **신뢰구간(추정치 ± 1.96·SE)**으로 표현하며, 차이의 구간이 0을 안 건드리면 "유의"의 냄새가 난다.
