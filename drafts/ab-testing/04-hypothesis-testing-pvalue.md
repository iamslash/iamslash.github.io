# 4편. 가설검정의 심장 (1) — 귀무가설과 p-value

> 시리즈: 밑바닥부터 이해하는 A/B 테스트 통계
> 이 편에서 배우는 것: "이 차이가 진짜인가, 아니면 그냥 운인가?"를 판정하는 사고방식(귀무가설)과, 그 판정의 핵심 숫자인 p-value.

콩마켓 실험 결과가 나왔습니다. 파란 버튼 A는 전환율 5.00%, 초록 버튼 B는 5.60%. 무려 **+0.6%p** 올랐네요. 회식 각일까요?

잠깐만요. 동전을 22,000번 던져도 앞면이 정확히 11,000번 나오지는 않습니다. 어떤 날은 11,050번, 어떤 날은 10,930번이죠. 전환율도 똑같습니다. 초록 버튼이 파란 버튼과 **아무 차이가 없더라도**, 방문자가 그날 누구였느냐에 따라 두 그룹의 전환율은 늘 조금씩 다르게 나옵니다. 그렇다면 이런 질문이 남습니다.

> +0.6%p라는 차이, 이건 초록 버튼이 진짜로 좋아서 생긴 걸까요? 아니면 그냥 운(우연)의 출렁임일까요?

이 질문에 확률로 답하는 도구가 **가설검정(hypothesis testing)** 입니다. 이번 편과 다음 편이 이 시리즈의 심장입니다. 천천히 가겠습니다.

## 재판 비유: 일단 "차이 없음"을 기본값으로 둔다

형사 재판을 떠올려 봅시다. 피고인은 유죄가 증명되기 전까지 **무죄로 추정(innocent until proven guilty)** 됩니다. 검사가 "합리적 의심을 넘어설 만큼" 강력한 증거를 내놓아야만 유죄가 됩니다. 증거가 어중간하면? 무죄입니다. "무죄임이 증명돼서"가 아니라, "유죄를 증명하지 못해서"요.

가설검정도 정확히 이 마음가짐입니다.

- **기본 입장(default):** "초록 버튼은 파란 버튼과 차이가 없다."
- 데이터(증거)가 이 기본 입장을 뒤집을 만큼 강력할 때만 "차이가 있다"고 선언합니다.
- 증거가 어중간하면? "차이가 있다고 말할 근거가 부족하다"에서 멈춥니다.

왜 이렇게 보수적으로 굴까요? 세상엔 우연이 넘쳐서, **아무 차이가 없어도 데이터는 늘 조금씩 다르게** 나오기 때문입니다. 조금만 차이가 나도 "차이 있다!"고 성급하게 외치면, 실제로는 헛것(우연)을 붙잡는 실수를 아주 자주 하게 됩니다. 그래서 판을 보수적으로 짜 둡니다.

## 두 개의 가설: 귀무가설과 대립가설

재판에 "무죄 추정"과 "검사의 주장"이 있듯이, 가설검정에도 두 개의 가설이 있습니다.

**귀무가설(null hypothesis, H0)** — "무죄 추정"에 해당하는, 우리가 기본으로 깔아두고 반증하려는 가설입니다.

- 콩마켓 버전: **"A와 B의 진짜 전환율은 같다(차이 = 0)."**
- 이름 풀이: '귀무(歸無)'는 "없음으로 돌아간다", 즉 "효과 없음"이라는 뜻입니다. 영어 null도 "0, 없음"이고요. 이 시리즈의 기본 우월성(superiority) A/B 검정에서는 H0를 "차이 = 0"으로 둡니다. 비열등성(non-inferiority)처럼 다른 질문에서는 H0에 0이 아닌 허용 한계를 둘 수도 있습니다.

**대립가설(alternative hypothesis, H1)** — 우리가 진짜로 주장하고 싶은 것, 검사의 주장에 해당합니다.

- 콩마켓 버전: **"A와 B의 전환율이 다르다(차이 ≠ 0)."**

여기서 헷갈리기 쉬운 포인트 하나. 재판에서 검사가 "피고인이 무죄가 아님"을 직접 증명하지 않듯, 우리도 H1을 직접 증명하지 않습니다. 대신 이렇게 접근합니다.

> "H0가 맞다고(차이가 없다고) 치자. 그런데 그런 세상에서 우리 데이터가 나오기가 이렇게나 힘들다고? 그럼 H0가 틀린 거 아냐?"

H0를 궁지로 몰아서 의심하게 만드는 것, 이게 가설검정의 전략입니다.

> 참고로 "다르다(≠)"는 초록이 더 **좋을** 수도, 더 **나쁠** 수도 있다는 양쪽을 모두 포함합니다(양측 검정). 한쪽 방향만 보는 단측 검정도 있지만, 기본은 양측입니다. 계산 디테일은 6편에서 다룹니다.

## p-value: H0가 맞다고 치고, 이 정도 차이가 우연히 날 확률

이제 이 시리즈에서 가장 중요한 단어가 나옵니다. 정의를 또박또박 읽어 주세요.

> **p-value** = 만약 H0가 참이라면(= 진짜로 차이가 없다면), 지금 우리가 관측한 것만큼 크거나 더 큰 차이가 **순전히 우연으로** 나올 확률.

핵심 감각은 이렇습니다.

- **p-value가 작다** = "H0가 맞다면 이런 일은 좀처럼 안 일어나는데, 실제로 일어나 버렸네?" → **H0가 의심스럽다.**
- **p-value가 크다** = "H0가 맞아도 이 정도 차이는 흔히 나오는데?" → **H0를 의심할 이유가 별로 없다.**

콩마켓에 적용해 봅시다. 관측된 차이는 +0.6%p였고, 계산해 보면 **p ≈ 0.005 (0.5%)** 가 나옵니다. 말로 풀면 이렇습니다.

> "진짜로 두 버튼에 차이가 없다면, 이만한 차이(또는 그 이상)가 우연히 나올 확률은 대략 **200번에 1번꼴**이다."

200번에 1번이면 꽤 드문 일이죠. 그런데 그 드문 일이 우리 실험에서 실제로 일어났습니다. 그래서 우리는 "차이가 없다(H0)"라는 기본 가정을 의심하게 됩니다.

비유하자면 p-value는 이런 겁니다. **"차이 없음"이라는 세계관(H0)을 잠깐 진짜라고 가정한 뒤, 그 세계에서 우리 데이터가 얼마나 희귀한 사건인지 재보는 것**입니다. 너무 희귀하면, "애초에 그 세계관 자체가 틀린 거 아냐?"라는 합리적 의심이 드는 거죠.

## p-value를 코드로 느껴보기

p-value는 공식으로도 구하지만(6편), 지금은 직관을 살리기 위해 **H0 세계를 컴퓨터로 100만 번 재현**해 보겠습니다.

아이디어는 단순합니다. H0는 두 전환율이 같다고만 말하고 공통 전환율이 몇 %인지는 알려주지 않습니다. 그래서 구매 2,332건 ÷ 방문 44,000명 = 5.3%를 공통값으로 추정합니다. 이제 "A도 5.3%, B도 5.3%인 세계"를 반복해서 만듭니다. 이 합친 값을 **pooled(합동) 비율**이라고 부릅니다. 그 가짜 세계에서 22,000명씩 두 그룹을 굴려 전환율 차이를 재고, **우리 관측(+0.6%p)만큼 극단적인 일이 얼마나 자주 나오는지** 세어 보면 됩니다. 그 비율이 바로 p-value입니다.

각 실험의 차이를 그대로 비교해도 되지만, 3편에서 배운 **표준오차(운으로 얼마나 출렁이는지의 크기)** 로 나눠 표준화(standardize)한 값(z)으로 비교하면 6편의 공식 계산과 정확히 같은 답이 나옵니다. 표준화 — 크기가 제각각인 차이를 '표준오차 몇 배냐'라는 같은 잣대로 바꾸는 것. 여기서 z는 관측 차이가 표준오차의 몇 배인지를 나타냅니다.

```python
import numpy as np

rng = np.random.default_rng(42)
n = 22_000            # arm별 방문자 수
trials = 1_000_000    # 가짜 실험을 100만 번

# 우리가 실제로 관측한 것
diff_obs = 1232/n - 1100/n          # +0.6%p
p_bar = (1100 + 1232) / (2*n)       # 두 그룹 합친 pooled 전환율 = 0.053
se = np.sqrt(p_bar*(1-p_bar)*(2/n)) # 2/n = 1/n + 1/n, 두 그룹 몫. 유도는 6편
z_obs = diff_obs / se               # 차이를 표준오차 단위로 = 2.81
print(f"관측 차이 = {diff_obs*100:.1f}%p, z = {z_obs:.2f}")

# H0 세계: 두 그룹의 공통 전환율 q를 pooled 비율 0.053으로 추정해 사용
p0 = p_bar            # H0 세계: A도 B도 전환율이 공통값 q = 0.053

# H0가 참인 가짜 세계를 100만 번 재현
A = rng.binomial(n, p0, trials)
B = rng.binomial(n, p0, trials)
pbar_s = (A + B) / (2*n)
se_s = np.sqrt(pbar_s*(1-pbar_s)*(2/n))  # 가짜 실험마다 나온 전환율로 잡음을 다시 재서, 6편 z-test와 같은 잣대로 비교
z_sim = (B/n - A/n) / se_s

# 우리 결과(z=2.81)만큼, 또는 그보다 더 극단적인 경우의 비율
p_value = np.mean(np.abs(z_sim) >= z_obs)
print(f"p-value(시뮬레이션) = {p_value:.4f}")   # ≈ 0.005
```

실제로 돌려 보면 이렇게 나옵니다.

```
관측 차이 = 0.6%p, z = 2.81
p-value(시뮬레이션) = 0.0050
```

"차이가 없는 세계"를 100만 번 재현했더니, 우리만큼 큰 차이가 우연히 벌어진 실험은 **0.5%**, 즉 200번에 1번뿐이었습니다. 공식 없이 시뮬레이션만으로도 p ≈ 0.005가 재현되는 것이죠. 이게 p-value의 밑바닥 정체입니다.

## p-value가 절대 아닌 것 (강력 경고)

p-value는 오해가 가장 많은 개념입니다. 아래 세 가지는 **틀린 해석**이니 확실히 새겨 두세요.

**1) p-value는 "H0가 참일 확률"이 아닙니다.**
p-value는 "H0가 참이라고 **가정한 상태에서** 데이터가 얼마나 희귀한가"입니다. "H0가 참일 확률"이 아니에요. 방향이 반대입니다.

- p-value가 답하는 것: P(이런 데이터 | H0가 참)
- 사람들이 착각하는 것: P(H0가 참 | 이런 데이터)

여기서 P(A | B)의 세로줄(|)은 "B라고 가정했을 때 A의 확률"로 읽습니다. 그래서 두 값은 조건과 결과가 뒤바뀐, 전혀 다른 확률입니다.

재판 비유로: **"당신이 무죄라면 이 증거가 나올 확률"** 과 **"이 증거를 봤을 때 당신이 무죄일 확률"** 은 전혀 다른 값입니다. p-value는 앞엣것이지 뒤엣것이 아닙니다.

**2) p-value는 "B가 이길 확률"이 아닙니다.**
p = 0.005라고 해서 "초록이 이길 확률이 99.5%"인 게 아닙니다. "B가 A보다 나을 확률(P(B > A))"에 **직접** 답하는 건 빈도주의가 아니라 베이지안(Bayesian)의 영역이고, 이건 11편에서 다룹니다. 지금 p-value로는 그 질문에 답할 수 없다는 것만 기억하세요.

**3) p-value는 효과의 크기가 아닙니다.**
p가 작다고 차이가 큰 게 아닙니다. 표본이 아주 크면 **눈곱만한 차이도** 작은 p를 만들어냅니다. "얼마나 유의한가(p)"와 "얼마나 큰 차이인가(효과 크기)"는 다른 질문입니다. 관측된 효과 크기는 B−A = +0.6%p(상대 +12%) 자체이고, 신뢰구간(3편)은 그 추정의 불확실성을 보여 줍니다. MDE(7편)는 실험 전에 목표 검정력으로 잡도록 설계한 최소 효과입니다.

> 덤: "p=0.05면 5% 확률로 틀린 거다" 같은 말도 자주 도는데, 이건 다음 편에서 다룰 유의수준 α 이야기와 뒤섞인 오해입니다. 5편에서 정리하겠습니다.

## 프레임워크에서 어디에 쓰이나

GrowthBook 같은 오픈소스 A/B 프레임워크의 결과 화면에서, 각 지표 옆에 뜨는 **"p-value"** 나 유의 여부 표시(초록/빨강)의 뿌리가 바로 이 계산입니다. 빈도주의(frequentist) 엔진은 지표마다 H0(차이 = 0)를 세우고 p-value를 계산해 "통계적으로 유의한가"를 판정합니다. 우리가 방금 손으로 돌린 100만 번 시뮬레이션을, 프레임워크는 닫힌 공식(z-test 등, 6편)으로 순식간에 해치우는 것뿐입니다.

## 한 줄 정리

p-value는 "차이가 없다(H0)고 가정했을 때 지금 같은 차이가 우연히 나올 확률"이며, 이 값이 작을수록 '차이 없음'이라는 기본 가정을 의심하게 됩니다 — 단, 이건 "H0가 참일 확률"도 "B가 이길 확률"도 아닙니다.
